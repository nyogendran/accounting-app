# Q-006: Will TIQACC take over data from a system in use today?

**Question.** SRC-001 2.16 covers migration and acceptance. If TIQACC takes over opening balances or
history from an accounting system in use today, the current chart of accounts is needed to map old
accounts to new ones (Q-005). If it starts fresh, it is not needed.

**Open.**

- Whether data is migrated.
- If it is, from which system and entities, and how much history.
