# Q-052: One group chart, or an entity's own chart

**Question.** Must every entity use the single group chart, or may an entity run its own chart?

**What SRC-007 says.**

- "A single group chart of accounts applies across all [No.] entities" (p.27, S7-2.2.1-c50).
- "An entity managing its own financial data independently is checked within itself; an entity posting to a shared group chart is checked across every entity on that chart" (p.29, S7-2.2.2-c16), and "Which chart an entity runs on is set at entity set-up" (c21).

**Why it matters.** It affects consolidation, the code-clash check and the phasing's risk R-03, which relies on a single group chart.

**Open.** Decision by the product owner, with the qualified accountant. Source: REV-01M5W2PMREVQFW5TCYYJQ1K1D6, finding 2.
