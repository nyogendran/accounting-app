# Q-049: Entity inside the account code (Design B)

**Question.** Is Design B (the entity inside the account code), offered in SRC-008, closed?

**What SRC-007 says.**

- Whose balance it is and which country it reports in "are segments presented around that code — never digits inside it" (p.25, S7-2.2.1-c16), and "Nothing in the software parses the reference to establish which entity or country a posting belongs to" (c23). SRC-008's "Entity in the code" sheet offers Design B on request.

**Why it matters.** SRC-007 appears to settle it; this confirms nobody is waiting on Design B.

**Open.** Confirmation by the product owner. Source: GOV-IMPACT-SRC007 v2, PQ-21.
