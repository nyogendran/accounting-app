# Q-048: Which specification version SRC-008 was prepared against

**Question.** Which specification version was the business information pack prepared against?

**What SRC-007 says.**

- SRC-008 says "Prepared against the requirement specification, version 1.1" ('Read me' r3). The baseline is SRC-007, version 2.2 (DEC-0008).

**Why it matters.** Where SRC-008 differs from SRC-007, it may be because it reflects an earlier version.

**Open.** Confirmation by the product owner, with the qualified accountant. Source: GOV-IMPACT-SRC007 v2, PQ-19.
