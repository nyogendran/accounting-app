# Q-033: The first entity's control enforcement level

**Question.** At what enforcement level, per control type, does Tiqri's first entity start? Does choosing a level below the delivered default at set-up count as a "lowering"?

**What SRC-007 says.**

- The delivered defaults are set by organisation (table on p.27): "Single entity, general ledger only": Not applied (S7-2.2.1-c58); "Single entity running sub-ledgers": "Advisory, and Enforced for bank" (c59); "Multi-entity group or consolidated reporting": Enforced (c60); "Multinational, multi-currency or high volume": "Enforced, and lowering it is reported" (c61).
- The level "is set per entity and per control type by the administrator" (c54).
- "Lowering a level from Enforced requires approval, a recorded reason and an effective date, and is reported to management on the governance panel in 2.15.8" (p.27, c64). Whether the 2.15.8 panel is in release 1 is open (phasing D-2.15.8).
- Q-003 v2 records several countries and multiple currencies, and the phasing plans a second entity in release 3. On that evidence Enforced (c60, c61) is the likely default, not Advisory. This is evidence, not a decision.

**Why it matters.** It decides whether interim manual journals are possible at all in release 1 (Q-029), and whether release 1 needs the governance panel.

**Open.** Decision by the qualified accountant, with the product owner. Sub-questions: (a) is the table read against Tiqri or against each entity; (b) is a lower level set at entity set-up a "lowering"; (c) if so, how it is approved and reported if 2.15.8 is not in release 1. Source: GOV-IMPACT-SRC007 v2, PQ-02.
