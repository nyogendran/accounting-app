# Q-039: Subscription and licensing (2.16.5) for Tiqri's own product

**Question.** How does 2.16.5 apply to Tiqri's own product, in which release, and with which commercial values?

**What SRC-007 says.**

- "Access is sold by subscription" (p.135, S7-2.16.5-c01). Section 3 now asks the vendor for prices, pack sizes and licence ratios (S7-3-c03). Tiqri is the vendor (Q-001).

**Why it matters.** 2.16.5 is new and has no release mark.

**Open.** Decision by the product owner, with the tech lead. Source: GOV-IMPACT-SRC007 v2, PQ-09.
