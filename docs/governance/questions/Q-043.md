# Q-043: Is approval to add an account ever optional

**Question.** Is approval to add or amend an account ever optional, as SRC-008's profile A says?

**What SRC-007 says.**

- "Once a chart is in use, every subsequent addition, amendment, reclassification or blocking of an account … follows the request, duplicate check, review and approval process in 2.2.2. There is no second route by which an account can appear" (p.26, S7-2.2.1-c44). SRC-008 ("Setup options") makes approval optional for a single entity running the ledger alone.

**Why it matters.** SRC-007 governs where SRC-008 differs; this confirms that it does here.

**Open.** Decision by the product owner, with the qualified accountant. Source: GOV-IMPACT-SRC007 v2, PQ-14.
