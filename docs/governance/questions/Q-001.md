# Q-001: What is TIQACC to Tiqri?

**Question.** SRC-001 reads as one organisation's requirements put to vendors: "Every clause is
answered in Annexure A as S standard, C configurable, X customisation with cost, or N not available"
(SRC-001 p.5). Is TIQACC (a) built for the organisation that wrote the specification, (b) Tiqri's own
multi-tenant SaaS product with that organisation as its first customer, or (c) something else?

**Answer so far** (governance owner, 2026-10-20): **(b)**. TIQACC is Tiqri's own multi-tenant SaaS
product, and the specification came from Tiqri's internal team.

**Consequences to confirm.**

- SRC-001 2.1.1 allows either tenancy model; this answer chooses multi-tenant.
- Annexure A's vendor-response format does not apply as written.
- Module acceptance (SRC-001 2.16.4) is by the internal team as the first customer.

**Open.** Confirmation by the product owner.
