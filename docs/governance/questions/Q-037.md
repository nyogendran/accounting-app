# Q-037: What the 2.2.2 acceptance statement tests

**Question.** Which module does each test in the 2.2.2 acceptance statement accept?

**What SRC-007 says.**

- The acceptance statement printed under 2.2.2 (p.31, S7-2.2.2-c61) mostly tests journal-upload mapping (2.2.4) and chart set-up and segments (2.2.1); only its last part tests 2.2.2.

**Why it matters.** Each test must be assigned to the module it accepts, or a module could pass acceptance on another module's test.

**Open.** Decision by the product owner. Source: GOV-IMPACT-SRC007 v2, PQ-06.
