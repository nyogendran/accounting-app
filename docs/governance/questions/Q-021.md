# Q-021: Statutory return forms, e-filing formats and prescribed invoice wording

**Question.** Which statutory return forms, e-filing file formats and prescribed invoice wording apply in each country?

**What SRC-001 says.**

- The tax register maps each return to its statutory form and e-filing format (S1-2.7.1-c11). Documents are exported in each jurisdiction's file format (S1-2.4.7-c04) and carry the wording prescribed by law (S1-2.4.3-c09).
- Titles and prescribed wording "are confirmed in user acceptance testing" (p.47, S1-2.4.4-c03).

**Why it matters.** The build needs the configurable mechanism. Each country's content is needed before that country's tax acceptance, not before the build starts.

**Open.** Decision by the tax specialist. Source: REV-01M5DADKQY1VNR1FMN2414KZ58.
