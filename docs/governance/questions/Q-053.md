# Q-053: Renumbering to resolve a code clash

**Question.** When an independent entity joins a group chart, may a code clash be resolved by renumbering?

**What SRC-007 says.**

- A clash "is resolved by mapping or by renumbering" (p.29, S7-2.2.2-c22).
- But "No account is renumbered to make room. A code issued is a code kept" (p.25, S7-2.2.1-c31), and "The account code itself can never be changed" (p.30, S7-2.2.2-c50).

**Why it matters.** It decides how an acquired or restructured entity joins the group chart.

**Open.** Decision by the qualified accountant, with the product owner. Source: REV-01M5W2PMREVQFW5TCYYJQ1K1D6, finding 2.
