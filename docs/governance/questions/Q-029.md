# Q-029: May payroll and depreciation be posted by manual journal until release 2?

**Question.** The proposed release phasing (`docs/requirements/release-phasing.yaml`, decision D-INT-1)
puts the payroll and fixed-asset modules in release 2. Until then, payroll and depreciation would be
posted by approved manual journals. Is that acceptable?

**What SRC-001 says.**

- "No user journal is acceptable as a substitute" (SRC-001 p.8, S1-2-c02).
- "Depreciation must be auto-calculated by the system, not by a spreadsheet." (p.77, S1-2.8.3-c01)

**Readings.**

- (A) Accept interim manual journals as a documented, time-limited exception for release 1.
- (B) No exception: payroll and fixed assets move into release 1.
- (C) Feed payroll from the current external system through the integration interface (Q-022), and
  move only fixed assets into release 1.

**Why it matters.** It sets the size of release 1. Under (A), BO-01's second indicator stays unmet
until release 2.

**Open.** Decision by the product owner, with the qualified accountant. Source: the requirements
steward's handoff for WF-01M5D0SE8MMS39CTPTXH8ME1HT step 4.
