# Q-022: External payroll feeding TIQACC by file

**Question.** May an entity that does not activate the payroll module feed payroll journals to TIQACC by file?

**What SRC-001 says.**

- "A third-party payroll product synchronising by file transfer is not acceptable" (p.90, S1-2.10-c01).
- "where it is not activated, the external system takes its place and feeds TIQACC" (p.11, S1-2.1.6-c14). File import is one of the interface methods (S1-2.1.6-c04).

**Readings.**

- (A) 2.10 constrains how TIQACC's own payroll module is delivered, and 2.1.6 governs entities that don't activate it.
- (B) No external payroll may feed TIQACC by file.
- (C) External payroll may feed only through the API.

**Assurance recommendation** (REV-01M5DADKQY1VNR1FMN2414KZ58, E4, advisory only): (A).

**Why it matters.** It decides what the integration framework must accept.

**Open.** Decision by the product owner. Source: REV-01M5DADKQY1VNR1FMN2414KZ58.
