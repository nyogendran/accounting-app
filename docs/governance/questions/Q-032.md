# Q-032: Control accounts: the blanket block or the enforcement levels

**Question.** For control accounts, which governs: the attribute table's blanket block, or the enforcement levels?

**What SRC-007 says.**

- The attribute table: control accounts "accept sub-ledger postings only; manual journals to them are blocked" (SRC-007 p.24, S7-2.2.1-c06).
- The posting rule: posting is blocked to "control accounts by manual journal where control enforcement is set to Enforced" (p.27, S7-2.2.1-c52).
- At Advisory, "A manual journal to a control account is allowed, requires a reason selected from a configurable list, and appears on an exception report to [role]" (p.27, S7-2.2.1-c56).

**Why it matters.** If the blanket block governs, Q-029's conflict is exactly as in V1. If the levels govern, a manual journal to a control account is possible below Enforced. Q-029 depends on this answer.

**Answer so far** (governance owner, 2026-10-28): "Let's go with - 'A manual journal to a control
account is allowed, requires a reason selected from a configurable list, and appears on an exception
report to [role]'. Role can be accountant or the defined role."

- This is the Advisory row of the posting rule (p.27, S7-2.2.1-c56) word for word. Read as an answer
  to this question: the enforcement levels govern, and the attribute table's blanket block (p.24) does
  not.
- The bracketed [role] in that row: the accountant, or a role the entity defines.
- Not yet clear: whether the answer also sets Tiqri's level to Advisory for every control type. That is
  Q-033, which the qualified accountant owns. V2.2 keeps bank at Enforced in every default where
  sub-ledgers run (S7-2.2.1-c59 to c61).
- Effect if confirmed: option A in Q-029 becomes possible without a change request or interim
  accounts, for any control type set at Advisory. Q-047 (the nil agreements) stays open.

**Open.** Confirmation by the product owner, who owns this question, with the qualified accountant
for the accounting effect; and whether the answer is meant to set the level as well (Q-033). Source: GOV-IMPACT-SRC007 v2, PQ-01.
