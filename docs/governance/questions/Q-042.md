# Q-042: The first entity's industry tax set

**Question.** Which industry tax set and levies apply to the first entity, in what order and on what base?

**What SRC-007 says.**

- An entity's industry selection "activates the industry tax set for that sector in that country — the levies the sector attracts, each with its rate, its base, its order of application against the transaction tax" (p.16, S7-2.1.7-c57). SRC-008 shows SSCL at 2.5% applied before VAT at 18%.

**Why it matters.** Levies print on every Sri Lanka invoice in release 1 if the entity is liable.

**Open.** Decision by the tax specialist. Source: GOV-IMPACT-SRC007 v2, PQ-12.
