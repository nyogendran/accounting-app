# Q-025: Default retention policy and one retention model

**Question.** What retention policy does a new tenant start with, and does one model (the longer of policy and statute) apply to all records, including those with a fixed "[7] years"?

**What SRC-001 says.**

- SRC-001 uses two models: six fixed "[7] years" clauses, and a configurable rule (S1-2.11.4-c05). The disposal rule (S1-2.11.4-c06) covers documents, but not other records.

**Why it matters.** The statutory periods per country are Q-020, for the tax specialist.
