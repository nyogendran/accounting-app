# Q-011: Correcting a posted depreciation run

**Question.** Is a posted depreciation run corrected by an adjustment journal, or reversed and recalculated?

**What SRC-001 says.**

- "the run itself is not re-run" (p.29, S1-2.2.6-c21).
- "A posted run can be reversed and recalculated only within an open period" (p.79, S1-2.8.5-c09), and a re-run of a closed period is blocked (S1-2.8.5-c10).

**Assurance recommendation** (REV-01M5DADKQY1VNR1FMN2414KZ58, E4, advisory only): Read S1-2.2.6-c21 as applying to closed periods. Within an open period, reversal and recalculation apply, as the acceptance test S1-2.8.16-c11 expects.

**Why it matters.** It sets the correction route the fixed-asset module must offer.

**Open.** Decision by the qualified accountant. Source: REV-01M5DADKQY1VNR1FMN2414KZ58.
