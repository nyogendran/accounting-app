# Q-034: Changing a control-account flag after transactions

**Question.** Can an account's control flag be set later, by approval, once the account has history, or only by opening a new account and reclassifying?

**What SRC-007 says.**

- "Changing the flag or the type on an account is a change to the chart and passes the approval in 2.2.2 like any other" (p.27, S7-2.2.1-c67).
- The control flag, "Once set, cannot be changed while the account carries a balance" (p.30, S7-2.2.2-c47).
- "Class, group and control-account status cannot be changed once transactions exist. A misclassified account is corrected by opening the correct account and reclassifying the balance by journal, with the working attached" (p.30, S7-2.2.2-c51).

**Why it matters.** If an account is not flagged in release 1, this decides whether it can be flagged at release 2 (Q-029, option A).

**Open.** Decision by the product owner, with the qualified accountant. Source: GOV-IMPACT-SRC007 v2, PQ-25.
