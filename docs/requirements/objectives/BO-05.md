# BO-05: Live management visibility, built by Finance without IT

Proposed by the requirements engineer in WF-01M5D0SE8MMS39CTPTXH8ME1HT step 4. The product owner
decides. Nothing below this line is normative.

## Evidence in SRC-001

- "gives management real-time visibility of financial performance" (SRC-001 p.4, overview, S1-0-c01)
- "Finance builds what it needs itself — by hand in a report designer, or by describing the report in
  writing — without the vendor, without IT and without a change to the system." (SRC-001 p.102, §2.13,
  S1-2.13-c01)
- "every figure is the ledger's, drawn live, and every figure leads back to the transaction that
  produced it" (SRC-001 p.114, §2.15, S1-2.15-c01)

## Indicators

All four indicators are SRC-001 acceptance tests with no bracketed value. In the proposed phasing the
report builder arrives in release 2 and the CFO dashboard in release 4, so these indicators are met
in stages; the governance panel (2.15.8) is a decision for the product owner (see
`docs/requirements/release-phasing.yaml`).

## Value to the first customer

The product owner is Tiqri's CFO; this objective is the one he uses directly.
