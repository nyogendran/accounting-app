# BO-08: Secure, confidential and available access from anywhere

Proposed by the requirements engineer in WF-01M5D0SE8MMS39CTPTXH8ME1HT step 6, in answer to
REV-01M5EP1W4DYPM707EB79AYEYV1 (finding 11(a)): no objective covered access, security,
confidentiality and availability, so the release-1 sub-sections 2.1.3 and 2.16.1 traced to none. The
product owner decides. Version 2 (step 8) links question record Q-031 for the tenant boundary, after
REV-01M5EQY9R7BC1SY2XDY6S9YA52. Nothing below this line is normative.

## Evidence in SRC-001

- "It is accessed through a browser from any location with no local installation" (SRC-001 p.4,
  overview, S1-0-c01)
- "Single sign-on against [identity provider], with multi-factor authentication compulsory for any
  access from outside the office network." (SRC-001 p.9, §2.1.3, 1, S1-2.1.3-c01)
- "Named-user licensing with the ability to disable a leaver immediately and retain their transaction
  history intact." (SRC-001 p.10, §2.1.3, 5, S1-2.1.3-c05)
- "Search respects permissions absolutely. A user who cannot open payroll records is never shown one
  in results, not even as a title." (SRC-001 p.10, §2.1.5, 4, S1-2.1.5-c13)
- "Payroll amounts are visible only to named payroll users and [role]. General finance users see the
  control totals and the departmental cost, never an individual salary." (SRC-001 p.98, §2.10.14, 1,
  S1-2.10.14-c01)
- A user sees only the entities assigned to them (S1-2.14.2-c15).
- Availability and backup targets (SRC-001 p.119, §2.16.1, S1-2.16.1-c03, c04), both bracketed.

## Indicators

All four are SRC-001's own. The first two are acceptance tests with no bracketed value and are in
release 1 of the proposed phasing (2.1.11 and the release-1 part of 2.14.14). The last two carry
bracketed values and are written with the brackets kept; they are not targets until the product
owner confirms them. SRC-001 also has a module-licensing test, "a user licensed for some modules
cannot reach the others through any screen, report, search or API call" (S1-2.1.7-c84, p.17); it is
not used here because that clause's release is a pending decision (D-2.1.7-c84).

## What this objective does not assume

It names no identity provider, encryption standard, hosting location or tenant model. Those are
decisions for the security owner and the tech lead, and the tenant model is an open item (OI-TENANT,
Q-031).

## Value to the first customer

Tiqri's finance team works from any location, and its financial and payroll data are seen only by the
people entitled to see them, with the service there when the team needs it.
