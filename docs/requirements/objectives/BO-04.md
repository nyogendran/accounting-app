# BO-04: Statutory and tax compliance in each jurisdiction, proved from the ledger

Proposed by the requirements engineer in WF-01M5D0SE8MMS39CTPTXH8ME1HT step 4. The product owner
decides. Nothing below this line is normative.

## Evidence in SRC-001

- "maintains compliance with the regulatory requirements of each jurisdiction the group operates in"
  (SRC-001 p.4, overview, S1-0-c01)
- "The system must hold the tax rules per entity, produce each return from the ledger, and prove the
  return back to the accounts — without a spreadsheet standing between the two." (SRC-001 p.68, §2.7,
  S1-2.7-c01)
- "No obligation in any jurisdiction is tracked outside the system." (SRC-001 p.72, §2.7.7,
  S1-2.7.7-c01)
- "A statutory series is gapless by enforcement, not by convention" (SRC-001 p.22, §2.1.10 Statutory
  sequences, 1, S1-2.1.10-c28)

## Indicators

All three indicators are SRC-001's own acceptance criteria and carry no bracketed value. This
objective states no tax rule: which taxes apply, and how, is configuration that the tax specialist
confirms for each country (Q-003, Q-021).

## Value to the first customer

Tiqri's Sri Lanka entity files its returns from the system and can prove each one back to the
ledger; Norway follows by configuration (BO-07).
