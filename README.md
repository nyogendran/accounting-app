# TIQACC

TIQACC is a cloud accounting and financial management system specified in
`requirement-doc/TIQACC-Cloud-Accounting-Requirement - V1.pdf`.

This repository is built under a governed, evidence-based engineering framework:
requirements, accounting knowledge, decisions, designs, code, tests and release
evidence are versioned here and linked by stable IDs. No application code exists
yet; the project is in lifecycle phase L0 (framework set-up).

## Where to start

| Read | For |
| --- | --- |
| `CLAUDE.md` | The rules every contributor and AI agent follows |
| `docs/governance/` | Methodology, conventions, operating model, authority matrix, decisions |
| `docs/sources/source-register.yaml` | Registered source documents and their SHA-256 fingerprints |
| `docs/governance/project-state.md` | Current phase, gate, open decisions and next steps |

## Status

- Lifecycle phase: L0, framework set-up (F0).
- Gate 0 (framework baseline): not yet approved.
- Nothing in this repository is an approved requirement until a decision record says so.
